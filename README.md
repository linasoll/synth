# ₊˚⊹☆⋆♫ Starlight Synth ♫⋆☆⊹˚₊ 

Интерактивный веб-синтезатор, созданный на JavaScript с использованием Tone.js.

В проекте воспроизводится аранжировка детской песни «Послушай» Зайчика Шнуфеля. Пользователь может запускать и останавливать композицию, управлять отдельными музыкальными партиями и изменять параметры их звучания в реальном времени.

В композиции используются партии Lead, Arpeggio, Bass, Bells, Drums и Hi-Hats. Для Lead и Arpeggio доступны дополнительные настройки тембра и эффектов.
